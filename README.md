# AlBayanSimile
**Problem & Solution**

This project focuses on detecting and interpreting simile (التشبيه) in Arabic text using a neuro-symbolic approach. Simile relies on specific linguistic patterns, such as particles like "كأن" and "مثل", which makes it suitable for rule-based detection, but purely symbolic methods lack flexibility, while neural models lack clear explanation. To address this, we designed a neuro-symbolic model that combines both. A symbolic system is used to identify simile structures in the sentence and convert them into an 11-dimensional feature vector that represents properties such as presence, type, confidence, and structural relationships. At the same time, a transformer model processes the sentence to capture its contextual meaning. The symbolic features are then integrated with the transformer representation, allowing the model to use both structured linguistic signals and contextual understanding. This enables the system to detect similes while also providing interpretable information about why a sentence is classified as a simile.
